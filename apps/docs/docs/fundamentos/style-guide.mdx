# Style guide

A direção é **lúdica e colorida**: base violeta profunda, acentos vibrantes,
cantos generosos e movimento com mola.

Tudo aqui é token. Um componente nunca escolhe cor nem tamanho de fonte na mão —
ele nomeia um papel ("superfície elevada", "texto secundário") e o tema decide o
valor. É o que faz o modo escuro existir sem duplicar componente nenhum.

## Cor

### As rampas

São sete: a da marca e seis acentos. Cada uma é uma rampa inteira de onze
degraus, e não um tom solto — é o que permite a um mesmo significado ter fundo
lavado, traço, texto legível e estado pressionado sem ninguém inventar cor na
hora.

As rampas não foram escolhidas a olho. São derivadas da curva da marca em
**OKLCH**: cada degrau repete o passo de luminosidade e a proporção de croma que
a marca tem naquele degrau, mantendo o matiz da cor e ancorando o **500** no tom
original. Por isso `mint-200` e `grape-200` pesam o mesmo na tela — coisa que
rampas escolhidas uma a uma quase nunca conseguem.

```jsx live
function Rampas() {
  return (
    <div style={{ display: 'grid', gap: 18 }}>
      {PALETTES.map((p) => (
        <div key={p.name}>
          <div style={{ display: 'flex', alignItems: 'baseline', gap: 8, marginBottom: 6 }}>
            <strong style={{ fontSize: 14 }}>{p.name}</strong>
            <span style={{ fontSize: 12, opacity: 0.7 }}>{p.means}</span>
          </div>
          <div style={{ display: 'flex', borderRadius: 10, overflow: 'hidden' }}>
            {RAMP_STEPS.map((n) => (
              <div
                key={n}
                title={`--color-${p.name}-${n}`}
                style={{
                  flex: 1,
                  height: 46,
                  background: `var(--color-${p.name}-${n})`,
                  color: n >= 500 ? '#fff' : 'rgba(0,0,0,.55)',
                  fontSize: 9,
                  display: 'flex',
                  alignItems: 'flex-end',
                  justifyContent: 'center',
                  paddingBottom: 3,
                }}
              >
                {n}
              </div>
            ))}
          </div>
        </div>
      ))}
    </div>
  )
}
```

### Papel e estado

Cor aqui não é decoração: cada acento carrega um significado fixo, e trocar o
acento de um papel troca o que a pessoa entende. O mapa mora no tema, em CSS —
quem usa declara o papel num atributo e lê o acento, sem nunca saber que
Front-End é ciano.

```jsx live
function PapelEEstado() {
  return (
    <div style={{ display: 'grid', gap: 20 }}>
      <div style={{ display: 'flex', flexWrap: 'wrap', gap: 20 }}>
        {Object.entries(ROLE_PALETTE).map(([papel, rampa]) => (
          <div key={papel} style={{ textAlign: 'center' }}>
            <Initials name={papel.replace('_', ' ')} role={papel} size="xl" />
            <div style={{ fontSize: 11, marginTop: 6 }}>
              <code>{papel}</code>
            </div>
            <div style={{ fontSize: 10, opacity: 0.6 }}>{rampa}</div>
          </div>
        ))}
      </div>

      <div style={{ display: 'flex', flexWrap: 'wrap', gap: 8 }}>
        {Object.keys(TONE_PALETTE).map((tom) => (
          <span
            key={tom}
            data-tone={tom}
            style={{
              background: 'var(--ds-accent-soft)',
              color: 'var(--ds-accent-ink)',
              border: '1px solid var(--ds-accent-line)',
              borderRadius: 999,
              padding: '6px 14px',
              fontSize: 12,
              fontWeight: 700,
            }}
          >
            {tom}
          </span>
        ))}
      </div>
    </div>
  )
}
```

### As variantes de um tom

Declarar um papel ou um estado entrega seis valores prontos, já resolvidos para
claro e escuro — é o contrato do Preline traduzido para o nosso tema. Nenhum
componente precisa saber qual rampa está por trás: ele lê `--ds-accent-ink` e
pronto.

```jsx live
function Variantes() {
  const [tom, setTom] = React.useState('critical')
  return (
    <div data-tone={tom} style={{ display: 'grid', gap: 12 }}>
      <div style={{ display: 'flex', gap: 6, flexWrap: 'wrap' }}>
        {['brand', 'positive', 'attention', 'critical', 'neutral'].map((t) => (
          <button
            key={t}
            onClick={() => setTom(t)}
            style={{
              cursor: 'pointer',
              borderRadius: 8,
              border: '1px solid var(--color-hairline, #ddd)',
              background: t === tom ? 'var(--ds-accent-soft)' : 'transparent',
              padding: '4px 10px',
              fontSize: 12,
            }}
          >
            {t}
          </button>
        ))}
      </div>
      <table style={{ fontSize: 12 }}>
        <tbody>
          {TONE_VARIANTS.map((v) => (
            <tr key={v.token}>
              <td style={{ width: 40 }}>
                <span
                  style={{
                    display: 'block',
                    width: 28,
                    height: 28,
                    borderRadius: 8,
                    background: `var(${v.token})`,
                    border: '1px solid rgba(0,0,0,.08)',
                  }}
                />
              </td>
              <td>
                <code>{v.token}</code>
              </td>
              <td style={{ opacity: 0.75 }}>{v.use}</td>
            </tr>
          ))}
        </tbody>
      </table>
    </div>
  )
}
```

## Tipografia

Três famílias com papéis distintos: **Outfit** para títulos, **Plus Jakarta
Sans** para texto e interface, **JetBrains Mono** para número que precisa
alinhar — código de sala, cronômetro, pontuação.

A escala segue razão 1.25 a partir de 16px. Os dois primeiros degraus quebram a
razão de propósito: rótulo em caixa alta precisa de corpo menor que o texto para
não competir com ele.

```jsx live
function Escala() {
  return (
    <div style={{ display: 'grid', gap: 10 }}>
      {TYPE_SCALE.map((t) => (
        <div key={t.token} style={{ display: 'flex', alignItems: 'baseline', gap: 16 }}>
          <code style={{ fontSize: 11, minWidth: 92 }}>{t.token}</code>
          <span style={{ fontSize: t.size, fontFamily: 'var(--font-display)', fontWeight: 900 }}>
            Planning Poker
          </span>
          <small style={{ fontSize: 11, opacity: 0.6 }}>
            {t.size} · {t.use}
          </small>
        </div>
      ))}
    </div>
  )
}
```

## Grid e espaçamento

Base de **4px**. Toda medida do produto é múltiplo dela, o que faz peças
diferentes alinharem sem ninguém precisar conferir.

```jsx live
function Espacamento() {
  return (
    <div style={{ display: 'grid', gap: 6 }}>
      {SPACE_SCALE.map((n) => (
        <div key={n} style={{ display: 'flex', alignItems: 'center', gap: 12 }}>
          <code style={{ fontSize: 11, minWidth: 40 }}>{n}</code>
          <div
            style={{
              height: 12,
              width: n * 4,
              borderRadius: 4,
              background: 'var(--color-brand-400)',
            }}
          />
          <small style={{ fontSize: 11, opacity: 0.6 }}>{n * 4}px</small>
        </div>
      ))}
    </div>
  )
}
```

As larguras de leitura têm nome: `prose` (42rem, limite de linha confortável),
`shell` (56rem, a largura da mesa) e `rail` (18rem, a barra lateral).

### Raios

Generosos, porque é isso que dá a sensação de brinquedo.

```jsx live
function Raios() {
  return (
    <div style={{ display: 'flex', gap: 16 }}>
      {RADII.map((r) => (
        <div key={r.token} style={{ textAlign: 'center' }}>
          <div
            style={{
              width: 84,
              height: 84,
              borderRadius: r.value,
              background: 'var(--color-brand-500)',
            }}
          />
          <div style={{ fontSize: 11, marginTop: 6 }}>
            <code>{r.token}</code>
          </div>
          <small style={{ fontSize: 10, opacity: 0.6 }}>{r.use}</small>
        </div>
      ))}
    </div>
  )
}
```

## Movimento

Duas curvas, com papéis separados:

| Curva | Quando |
|---|---|
| `--ease-spring` | O que a pessoa acionou — precisa responder |
| `--ease-out-soft` | O que acontece sozinho — não deve chamar atenção |

E quatro durações: `instant` (120ms), `quick` (200ms), `settle` (300ms),
`scene` (500ms). Tudo respeita `prefers-reduced-motion`.
